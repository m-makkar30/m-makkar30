#### 📡 [WebSentinel 🔗](https://github.com/m-makkar30/WebSentinel)

Web change-intelligence platform — watches the pages that matter to a business and raises a plain-language alert only when something meaningful actually changes. The hard part is noise suppression: telling a real change (a price move, a new data-retention clause) apart from cosmetic churn like rotating ads and session IDs — via field diffs + normalized text + pgvector embeddings.

**Stack:** React / Vite / TypeScript / Tailwind v4 / shadcn/ui | Django / DRF | Celery / Celery Beat / Redis | PostgreSQL / pgvector | Playwright | NVIDIA NIM | Docker
