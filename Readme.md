### 🐍 Contribution snake

![snake animation](https://raw.githubusercontent.com/m-makkar30/m-makkar30/output/github-contribution-grid-snake-dark.svg)

<details>
<summary><i>Setup (one-time)</i></summary>

This snake renders only after you set up the GitHub Action that generates it.

1. In this repo (`m-makkar30/m-makkar30`), create `.github/workflows/snake.yml` with:

   ```yaml
   name: Generate Snake
   on:
     schedule: [{ cron: "0 */24 * * *" }]
     workflow_dispatch:
     push: { branches: ["main"] }

   jobs:
     generate:
       runs-on: ubuntu-latest
       permissions: { contents: write }
       steps:
         - uses: Platane/snk@v3
           with:
             github_user_name: m-makkar30
             outputs: |
               dist/github-contribution-grid-snake-dark.svg?palette=github-dark
         - uses: crazy-max/ghaction-github-pages@v3
           with:
             target_branch: output
             build_dir: dist
           env:
             GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
   ```

2. Commit. The action runs daily and pushes the SVG to an `output` branch — the image link above will start working within a few minutes.
